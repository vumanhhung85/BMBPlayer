Boom Music Box Player

Bản học cơ chế: phát bằng trình phát nhúng chính thức của YouTube (IFrame Player API). Mở remote.html ở tab khác để tìm và chọn bài. Phím tắt: Space phát/dừng · → bài kế · M tắt tiếng.

Trang đang mở bằng file://. YouTube yêu cầu trang nhúng có địa chỉ http(s) nên video sẽ báo lỗi 153. Hãy chạy python -m http.server 8000 trong thư mục chứa file rồi mở http://localhost:8000/, hoặc đưa lên GitHub Pages.
Hàng chờ trống — chọn bài từ remote.
